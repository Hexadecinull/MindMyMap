# MindMyMap - Browser Extension

Open MindMyMap in one click from any browser tab.

## Features

- 🧠 One-click access to your MindMyMap server
- 🗺️ Recent maps list (auto-tracked as you browse)
- 🔗 Configurable server URL
- 🟢 Server reachability indicator

## Install (Developer / Self-hosted)

1. Open `chrome://extensions` (Chrome) or `edge://extensions` (Edge)
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this `mindmymap-extension/` folder

## Configure

Click the extension icon → enter your server URL → click Save.

Or right-click the extension icon → **Options**.
